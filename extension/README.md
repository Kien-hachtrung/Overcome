# overcum site blocker

1. Open `chrome://extensions` or `edge://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this `extension` folder.
4. Open the extension popup and enter the same domains saved in overcum Settings.

The extension watches completed tab navigations, including direct visits and subdomains, then closes matching tabs. A normal website cannot do this by itself because browser pages cannot monitor or close unrelated tabs.
